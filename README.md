# 🛒 Zepto SQL Data Analytics Project

A beginner-friendly SQL data analytics project built on a real-world Zepto inventory dataset. It walks through how data analysts use SQL to clean, explore, and analyze e-commerce data to surface business insights.

Good fit for:

* 📊 Data analytics beginners
* 📚 Students learning SQL
* 💼 Portfolio and resume projects
* 🚀 Practice with real-world business problems

---

## 📌 Project Overview

This project performs an end-to-end SQL-based analysis of Zepto's product inventory data.

The workflow covers:

✅ Data cleaning
✅ Data exploration
✅ Business insight generation
✅ Real-world SQL query practice

---

## 📁 Dataset Information

The dataset holds product inventory records from Zepto, including:

* Product name
* Category
* MRP
* Discount percentage
* Selling price
* Stock availability
* Product weight
* Inventory quantity

It's built to mirror the kind of data analysts actually work with in e-commerce.

---

## 🔍 Business Problems Solved

### Q1. Top 10 best-value products by discount percentage

### Q2. Products with high MRP that are out of stock

### Q3. Estimated revenue per category

### Q4. Products priced above ₹500 with less than 10% discount

### Q5. Top 5 categories with the highest average discounts

### Q6. Price per gram for products above 100g

### Q7. Grouping products into Low, Medium, and Bulk weight categories

### Q8. Total inventory weight per category
